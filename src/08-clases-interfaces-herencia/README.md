# 08. Clases, interfaces y herencia

Aquí están los ejemplos de clases, interfaces, encapsulación, herencia y clases abstractas. Los ejercicios de esta unidad están en `ejercicios/`.

`objetos.ts` presenta primero objetos tipados, propiedades opcionales y `readonly`. Tanto los alias (`type`) como las interfaces describen formas de objeto y se comprueban estructuralmente: un valor es compatible si tiene las propiedades requeridas.

`requisitos.ts` modela un pedido y calcula su total a partir de sus artículos. Sirve para practicar cómo traducir una regla de negocio a tipos y una función reutilizable. También muestra que los tipos no sustituyen la validación en ejecución de un porcentaje recibido desde fuera.
