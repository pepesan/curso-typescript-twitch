# Ejercicios de clases: raza y nombre

Estos ejercicios complementan las prácticas existentes de la unidad 08; no las reemplazan.

- `ejercicioAnimal.ts` demuestra constructor predeterminado, getter, setter y `display()` para la raza.
- `ejercicioPerro.ts` demuestra herencia, llamada a `super`, acceso a la raza heredada y el nombre propio de `Perro`.

Las clases están separadas en `AnimalRaza.ts` y `PerroRaza.ts`. En la aplicación, cada ejercicio aparece como una entrada separada del submenú de la unidad.
