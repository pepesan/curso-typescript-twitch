# Aplicación del curso

`courseCatalog.ts` describe las unidades y enlaza cada ejemplo con su código y demostración. `courseApp.ts` controla la selección, la URL y la vista del ejemplo activo. El índice de unidades está en la navegación lateral de escritorio y en el menú hamburguesa de móvil. El submenú de ejemplos aparece en el contenido de la lección, debajo de la descripción y justo antes del ejemplo activo; en móvil se abre un desplegable propio con opciones estiladas y accesibles por teclado. Al elegir una unidad desde el menú móvil, este se cierra y el foco pasa al desplegable de ejemplos. Al elegir un ejemplo, el código y su resultado quedan visibles juntos. El código fuente se carga como texto con `import.meta.glob` (`?raw`) usando la ruta relativa a la raíz del proyecto; esa misma ruta se muestra encima de cada bloque de código. Solo se ejecuta la demostración seleccionada.
