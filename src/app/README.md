# Aplicación del curso

`courseCatalog.ts` describe las unidades y enlaza cada ejemplo con su código y demostración. `courseApp.ts` controla la selección, la URL y la vista del ejemplo activo. El índice de unidades está en la navegación lateral de escritorio y en el menú hamburguesa de móvil. El submenú de ejemplos aparece en el contenido de la lección, debajo de la descripción y justo antes del ejemplo activo; en móvil se usa un selector desplegable para que todas las opciones sean accesibles. Al elegir una unidad desde el menú móvil, este se cierra y el foco pasa al primer ejemplo de la unidad. Al elegir un ejemplo, el código y su resultado quedan visibles juntos. El código fuente se carga como texto con `?raw`; solo se ejecuta la demostración seleccionada.
