# Aplicación del curso

`courseCatalog.ts` describe las unidades y enlaza cada ejemplo con su código y demostración. `courseApp.ts` controla la selección, la URL y la vista del ejemplo activo. Al elegir una unidad, sus ejemplos aparecen como submenú; al elegir uno, el código y su resultado quedan visibles juntos. El código fuente se carga como texto con `?raw`; solo se ejecuta la demostración seleccionada.
