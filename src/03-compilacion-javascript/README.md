# 03. Compilación a JavaScript

TypeScript añade comprobación estática y se transforma en JavaScript para ejecutarse. En este proyecto, `npm run build` ejecuta el compilador de TypeScript y después Vite genera la aplicación de producción en `dist/`. `npm run preview` sirve ese resultado localmente para revisar el paquete final. La configuración usa rutas relativas para que la carpeta también se pueda alojar bajo una subruta.
